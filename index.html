  • 作品写真の反応率を、スマホとカメラで比べるときの注意

    撮影の記録からカメラ・スマホごとの使えた割合と反応率を出す表の作り方と、背景・光・出品先・作品の違いが混ざるときの比べ方の注意。

  • 作った数の記録から、新作が出す日に間に合うかを「いまのペース」で見る

    制作の記録から直近7日に作った数を SUMIFS で出し、1日のペース・終わるまでの日数・見込みの完成日を式で出して、見積もりの判定と比べる方法。

  • ハンドメイドの作業時間を、種類ごとの割合で全期間と直近30日で比べる

    制作・撮影・梱包・SNS などの作業時間を種類ごとの割合にして、全期間と直近30日で並べて比べる方法。直近30日の割合の式と読み方の注意つき。

  • 作品写真の反応率を、minne・Creema など出品先ごとに分けて比べる

    minne・Creema・Instagram で閲覧の数え方が違うため、SUMIFS に出品先の条件を足して、出品先をそろえて作品写真の反応率を比べる方法。

  • 作品写真の光の当て方ごとに反応率を比べる(合計どうしで割る理由)

    窓の自然光・撮影用ライトなど光の当て方ごとに作品写真の反応率を出し、合計どうしで割る数字と1行ずつの反応率の平均の違いを説明。

同人・BOOTH の頒布と収支

  • 同人イベントの収支を出す方法|参加費・交通費・頒布数から黒字か赤字かを一目で

    参加費・交通費・頒布数から、同人イベント1回分の収支を出す手順。頒布した分の原価で見るか、刷った全部の印刷代で見るかの違いも説明します。

  • 新刊を何部刷るか決めるときに見る3つの数字(過去の頒布数・在庫・損益分岐点)

    新刊の部数を、過去の頒布数・既刊の在庫・損益分岐点の3つの数字から決める方法。50部と100部で、需要ごとに残るお金を比べます。

  • 頒布数と在庫をスプレッドシートで管理する|SUMIFS で作品ごとに自動集計

    頒布記録を1行ずつ書き、SUMIFS で作品ごとの頒布数・在庫・売上を自動で集計する表の作り方。数が合わないときの確かめ方つき。

  • イベントと通販の売上を1つの表にまとめるやり方

    イベントと通販(BOOTH など)の頒布を1枚の記録にまとめ、SUMIFS で場所ごとの部数・売上・収支を出す方法。通販だけ・イベントだけの合計の出し方つき。

  • BOOTH の売上をスプレッドシートで月別に集計する|SUMIFS と EOMONTH で月ごとの合計を出す

    日付の入った BOOTH の売上の記録から、SUMIFS と EOMONTH で月ごとの金額・数を出し、前の年の同じ月と比べる表の作り方。

  • 1年分のイベント収支を振り返る表の作り方|年ごとの合計と黒字・赤字の回数を式で出す

    イベントの表に日付を入れ、SUMIFS と COUNTIFS で年ごとの費用・売上・収支と、黒字・赤字の回数を出す方法。1部あたりの費用の見方つき。

  • 無料配布・献本・イベント限定価格を、売上の集計でまちがえない書き方|単価を上書きする1列で分ける

    献本・無料配布・イベント限定価格・セット販売を、頒布記録の「単価(上書き)」の1列で書き分け、在庫と売上を合わせる方法。

  • 新刊の頒布数を、イベントごとに前回と比べる表|SUMIFS の2条件で「作品 × イベント」を出す

    頒布記録から SUMIFS の2条件で「作品 × イベント」の表を作り、前回との差を、その回の新刊を除いた部数でも比べる方法。

ハンドメイドの値段と利益

  • ハンドメイド作品の原価の出し方|材料の単価から1点分の材料費を計算する

    まとめ買いした材料の単価から、ハンドメイド作品1点分の材料費を出す手順。型や道具の分の入れ方、端数の扱いも説明します。

  • ハンドメイド作品の値段の決め方|手数料・送料・作業時間から販売価格の目安を出す

    手数料・梱包・送料・作業時間を入れて、ハンドメイド作品の販売価格の目安を逆算する方法。「材料費の3倍」で足りるかも比べます。

  • ハンドメイドイベントの出店で、いくら残ったかを出す方法|出店料・交通費・決済手数料・原価から利益と時給を計算する

    マルシェ・手づくり市の出店1回分の利益を、売上から決済手数料・原価・出店料や交通費を引いて出す方法。時給と目標の達成率も式で出します。

  • ハンドメイドの売上を販売先ごとに集計する|minne・Creema・イベントで手数料率が違うとき

    minne・Creema・イベントなど手数料率の違う販売先の売上を、1行ごとの手数料と SUMIFS で販売先ごとに集計する方法。利益率の見方の注意つき。

  • ハンドメイドの売上を月別に集計して、去年と比べる|手数料・原価を引いた利益で見る

    ハンドメイドの販売記録から、SUMIFS で月ごとの売上・手数料・原価・利益を出し、前の年の同じ月の利益と前年比で比べる方法。

  • 委託手数料と卸の掛け率で、手元に残る額を比べる|同じ作品を委託・卸・自分の通販で並べる

    同じ作品を委託・卸・自分の通販で売ったときの1点の利益を並べ、売れ残りを入れた比べ方と、お店ごとの受け取り額・未入金・利益の出し方を説明します。

  • 受注制作の時給を出す|代金・手数料・材料費・作業時間から1件ごとに

    受注制作の注文ごとに、代金・送料・手数料・経費・作業時間から利益と時給を出す方法。時給の目標に届く代金を逆算する式つき。

  • ハンドメイドの作業時間を記録して、作品ごとの時給を出す|開始・終了・休憩から

    作業の記録を1回1行で書き、開始・終了・休憩から作業の時間を出して、作品ごとの1点あたりの時間・時給・目標の時給にとどく価格を式で出す方法。

  • 作品に入らない作業も入れた、ハンドメイド全体の時給を出す|撮影・梱包・買い出しの時間

    撮影・梱包・材料の買い出しなど作品に入らない作業の時間を種類別に集め、その時間も入れた全体の時給を、作品の時間だけの時給と比べる方法。

  • ハンドメイドの作業時間を月別に集計して、作品に入らない時間の割合を見る

    作業の記録から SUMIFS で月ごとの時間の合計・制作の時間・作品に入らない時間・作った数を出し、割合と1点あたりの制作時間を月ごとに比べる方法。

  • ハンドメイドの作業時間を、種類ごとの割合で全期間と直近30日で比べる

    制作・撮影・梱包・SNS などの作業時間を種類ごとの割合にして、全期間と直近30日で並べて比べる方法。直近30日の割合の式と読み方の注意つき。

在庫・材料・委託

  • 在庫が少なくなったら色で知らせる|条件付き書式の設定

    在庫が5部以下の行を黄色、0部未満(数えまちがい)の行を赤にする条件付き書式の設定。Excel・Google スプレッドシート・LibreOffice の手順つき。

  • マルシェに何個持っていくか|前回の「売れた割合」から持ち込み数を決める

    マルシェ・手づくり市に持っていく作品の数を、前回の持ち込み数と売れた数から決める方法。SUMIFS の2条件で売れた数と売れた割合を出します。

  • ハンドメイド作品の在庫を、販売記録から自動で減らす|作品名の打ちまちがいで減らないときの対策

    作った数だけを書き、販売記録から SUMIFS で売れた数を集めて在庫を自動で出す方法。作品名の打ちまちがいで在庫が減らないときの見つけ方と防ぎ方つき。

  • 委託販売で、お店ごとに預けた数・売れた数・お店にある数を管理する|SUMIFS の2条件で「お店 × 作品」

    委託販売の納品と販売報告を1行ずつ書き、SUMIFS の2条件でお店 × 作品の預けた数・売れた数・引き取った数・お店にある数・売れた割合を出す方法。

  • ハンドメイドの材料・パーツの在庫を、仕入れた数と使った数から出す|買い足す時期を式で知らせる

    金具・ビーズ・糸などの材料の残りを、仕入れた数と使った数から SUMIFS で出し、目安を下回った材料に「買い足す」と出して買い物リストに並べる方法。

  • 材料の単価を仕入先ごとに比べる|最後に買った単価と、いちばん安かった仕入先を式で出す

    仕入の記録から送料込みの単価を出し、材料ごとに最後に買った単価・いちばん安かった単価と仕入先を LOOKUP・MINIFS・INDEX/MATCH で出す方法。

  • しばらく売れていない作品を式で見つける|MAXIFS で「最後に売れた日」と日数を出す

    販売記録から MAXIFS で作品ごとの最後に売れた日を出し、たった日数と直近90日の販売数で、在庫が残ったまま止まっている作品に印をつける方法。

新作の計画・注文・出品・SNS・お客さま対応

  • 出店の持ち物チェックリストをスプレッドシートで作る|「済」を選ぶと行の色が変わる

    マルシェ・手づくり市の持ち物チェックリストを、入力規則の「済」と条件付き書式で作る方法。残りの数を COUNTIF で出し、イベントごとに使い回します。

  • オーダーメイドの注文を、納期の近い順に並べる表|発送済みを除いて SMALL・INDEX/MATCH で

    オーダーメイドの注文から、発送済み・キャンセルを除いて納期の近い順に並べる表の作り方。TODAY・SMALL・INDEX/MATCH と SORT・FILTER の書き方つき。

  • ハンドメイド作品の出品準備を表で管理する|進み具合と「次にやる作業」を式で出す

    ハンドメイド作品の出品までの作業を「済」で消していき、進み具合(%)と次にやる作業を式で出す表の作り方。出品先ごとの状態の一覧つき。

  • SNS 投稿の反応を記録して、種類別・曜日別に平均で比べる|AVERAGEIFS と反応率の出し方

    Instagram・X などの投稿を1行ずつ記録し、反応の合計と反応率を式で出して、AVERAGEIFS で SNS 別・種類別・曜日別の平均を比べる方法。

  • SNS の投稿予定を表で管理する|「遅れ」「今日」を色で出し、最後に投稿してからの日数を MAXIFS で

    SNS の投稿の予定日と投稿した日を1行に書き、遅れ・今日を色で出す方法。SNS ごとの最後に投稿した日・たった日数・次の予定日を MAXIFS・MINIFS で出します。

  • ハンドメイドのお客さま対応で、返信忘れを式で知らせる|minne・Creema・DM の問い合わせを1枚に

    minne・Creema・DM などの問い合わせを1件1行で記録し、返信した日が空の行に未返信、目安の日数を過ぎた行に遅れと式で出す方法。窓口ごとの返信までの日数つき。

  • お客さまごとの購入回数で、リピーターを見分ける|COUNTIFS と最後の連絡からの日数

    お客さまとの連絡の記録から、COUNTIFS・SUMIFS でお客さまごとの購入の回数と合計を出し、リピーター・最後の連絡からの日数・評価の平均を式で出す方法。

  • 新作をイベントや特集の日までに間に合わせる|1日に要る作業時間を式で出す

    新作の作る数と1点の作業時間から残りの作業時間を出し、先に来る出す日の分も入れて、出す日までに1日に何時間作業すれば間に合うかを式で出す方法。

  • 出す先ごとに、間に合うかと売上・利益の目安をまとめる|ハンドメイドの新作の計画

    イベント・minne・Creema など出す先ごとに、作る数・残りの作業時間・1日に要る時間・間に合うかと、売上と利益の目安を SUMIFS でまとめる方法。

  • 作った数の記録から、新作が出す日に間に合うかを「いまのペース」で見る

    制作の記録から直近7日に作った数を SUMIFS で出し、1日のペース・終わるまでの日数・見込みの完成日を式で出して、見積もりの判定と比べる方法。

作品写真の撮り方と反応

  • 作品写真の撮り方を記録して、背景ごとに「使えた割合」と反応率を比べる

    作品写真の撮影ごとに背景・光・撮った枚数・使った枚数・閲覧数・お気に入りを記録し、SUMIFS で背景ごとの使えた割合と反応率を比べる方法。

  • 作品写真の光の当て方ごとに反応率を比べる(合計どうしで割る理由)

    窓の自然光・撮影用ライトなど光の当て方ごとに作品写真の反応率を出し、合計どうしで割る数字と1行ずつの反応率の平均の違いを説明。

  • 作品写真の反応率を、minne・Creema など出品先ごとに分けて比べる

    minne・Creema・Instagram で閲覧の数え方が違うため、SUMIFS に出品先の条件を足して、出品先をそろえて作品写真の反応率を比べる方法。

  • 作品写真の反応率を、スマホとカメラで比べるときの注意

    撮影の記録からカメラ・スマホごとの使えた割合と反応率を出す表の作り方と、背景・光・出品先・作品の違いが混ざるときの比べ方の注意。

式の書き方

  • 作品名から価格を引く式|VLOOKUP・INDEX/MATCH・XLOOKUP のどれを使うか

    作品名から価格や原価を引く式を、VLOOKUP・INDEX/MATCH・XLOOKUP の3つで比べる。見つからないときの IFERROR、空白で見つからないときの TRIM も。

  • 入力のまちがいを色で知らせる|登録していない名前・空欄・重なりを条件付き書式で見つける

    作品の表に無い名前・書き忘れた空欄・作品名の重なりを、COUNTIF の条件付き書式で赤にして、集計がずれる前に気づく方法。

  • よく売れた作品の順位を式で出す|LARGE・INDEX/MATCH で上位3つ、同じ金額でも重ならない書き方

    売上の合計の上位3つを LARGE・INDEX/MATCH で出す方法。同じ金額で同じ作品が2回出る問題を RANK と COUNTIF で直し、SORT・FILTER の書き方も比べます。
