SNS への投稿に使うアプリについて

ますめ堂は、自分の SNS のアカウント(Pinterest・Instagram・Threads・YouTube など)に投稿を予約・公開するために、各サービスの公式の API を使う小さなアプリを準備しています。使い始めてからは、次のとおりに扱います。このアプリは、ますめ堂が持つアカウントだけで使い、ほかの方がログインして使うことはできません。

  • 扱う情報: ますめ堂のアカウントの認証の情報(アクセストークン)と、ますめ堂が投稿する画像・文・リンク、投稿の表示回数などの数字だけです
  • ほかの方の情報: フォロワーや閲覧した方の個人を特定できる情報は、集めず、保存せず、第三者に渡しません
  • 保存の場所: 認証の情報は、ますめ堂が管理する環境に保存し、各サービスの API を使う目的のほかには外部に送りません
  • 使う目的: 投稿の予約・公開と、どの投稿がよく見られたかの確認のためだけに使います
  • 削除: アプリとの連携は、各サービスの設定の「連携しているアプリ」からいつでも解除できます。解除したときや、アプリを使わなくなったときは、保存している認証の情報と数字を削除します。削除のご依頼は、下の「お問い合わせ」からお願いします
  • YouTube について: このアプリで YouTube を扱うときは、YouTube API サービスを使います。YouTube の利用には YouTube 利用規約が適用され、Google による情報の扱いは Google プライバシー ポリシーのとおりです
  • 連携の取り消し: Google のアカウントとの連携は、Google のセキュリティ設定のページからいつでも取り消せます
  • 削除の期間: 削除のご依頼を受けたときは、7日以内に削除します。投稿の数字などの保存は30日までとし、それより古いものは削除するか取り直します
  • Pinterest・Instagram・Threads の API から受け取った情報は、上の目的のほかには使わず、販売・広告には使いません
