ハンドメイドの作業時間を記録して、作品ごとの時給を出す|開始・終了・休憩から

公開日: 2026-11-11

ハンドメイドの値段を見直したいとき、いちばん手元に無い数字が「1点を作るのに何時間かかったか」です。材料費は買ったときのレシートで分かりますが、時間は書いておかないと残りません。

この記事では、作業の記録を1行ずつ書き、開始・終了・休憩から作業の時間を出して、作品ごとに「1点あたりの時間」と「時給の目安」を式で出します。目標の時給にとどく価格も逆算します。

作業の記録は1回1行

作業をしたら、日付・作品・作業の種類・開始・終了・休憩を1行に書きます。時刻を控えていなかったときは、G 列に分で直接書きます。

J 列(作業の時間)は、分の列があればそれを使い、なければ開始・終了・休憩から出します。

J2: =IF(ISNUMBER($G2),$G2/60,IF(AND(ISNUMBER($D2),ISNUMBER($E2)),MOD($E2-$D2,1)*24-N($F2)/60,""))
  • 時刻は「1日 = 1」の小数で入っているので、差に 24 をかけると時間になります(9:00〜11:30 は 2.5)
  • MOD(終了−開始,1) にしておくと、日付をまたいだ作業も正しく出ます。22:30〜0:30 は、そのまま引くとマイナスになりますが、MOD で 2.00 になります。ただし時刻だけを見ているので、1行は24時間未満の作業に限ります。夜通しで長くなったときは、日ごとに行を分けて書きます
  • 休憩は分で書き、60 で割って引きます。13:00〜17:00 で休憩30分なら 3.50 です
  • 作った数(H 列)は、その作業で仕上がった数だけを書きます。同じ作品の出品作業の行などは空にしておきます

作品ごとに集めて、1点あたりの時間と時給を出す

作品の表では、作品名を条件に SUMIFS で作業の時間と作った数を集めます。

E2(作業の時間の合計): =SUMIFS(作業!$J$2:$J$3001,作業!$B$2:$B$3001,$A2)
F2(作った数):         =SUMIFS(作業!$H$2:$H$3001,作業!$B$2:$B$3001,$A2)
G2(1点あたりの時間):  =IF(N($F2)<=0,"",$E2/$F2)
H2(1点の利益):        =$B2-$B2*$D2-$C2              価格 − 手数料 − 材料費
I2(時給の目安):       =IF(OR($G2="",$H2=""),"",IF($G2<=0,"",$H2/$G2))

(テンプレートでは、作品名が空のときに空を返す IF を外側につけています。I2 の内側の IF は、作った数はあるのに時間が 0 の行で 0 で割らないためのものです)

ピアスは3時間で5点なので、1点 0.6時間です。利益 900円 ÷ 0.6時間 = 時給 1,500円 になります。がま口ポーチは2点に 4.75時間かかっていて、1点 2.38時間・時給 884円 です。目標の時給(この例は 1,000円)を下回った行は、条件付き書式でオレンジにしています。

作品名は、作品の表と作業の記録で一文字も違わずにそろえます。打ちまちがいがあると、その行の時間が作品に入りません。反対に、作品の表に同じ作品名を2行書くと、両方の行に同じ時間が集まり、全体の数字が大きく出ます。そろえ方は入力のまちがいを色で知らせる記事で説明しています。

目標の時給にとどく価格を逆算する

1点の利益が「目標の時給 × 1点の時間」になる価格は、手数料の分を割り戻して出します。

J2: =ROUNDUP((設定!$D$2*$G2+N($C2))/(1-N($D2)),-1)
  • 設定!$D$2 が目標の時給、G が1点の時間、C が材料費、D が手数料の率です
  • ROUNDUP の -1 で10円単位に切り上げます

ポーチは (1,000 × 2.375 + 600) ÷ 0.9 = 3,305.5… で、3,310円 になります。いまの 3,000円 とは 310円 の差です。値上げするか、作り方を見直して時間を減らすかを、この差を見て決めます。値上げの前と後で時給と月の利益を並べて比べる方法は、値上げの前と後の時給の記事にまとめました。送料や梱包の費用も入れて値段を考える方法は、ハンドメイド作品の値段の決め方の記事で説明しています。

撮影や梱包の時間はどうするか

撮影・材料の買い出し・梱包のように、作品を決めずにまとめてした作業は、作品を空にして書いておきます。この時間は作品ごとの時給には入りません。そのぶん、作品の時給は実際より高く見えます。作品に入らない時間も入れた全体の時給は、次の記事で出します。

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、設定・作品・作業・作業別・月別をまとめたテンプレートで作りました。作業の種類ごとの時間や、月ごとの時間・作った数も式で出ます。表を一から作る時間を省きたい方は、ハンドメイド作家の作業時間の記録と時給の目安シートもご覧ください。
