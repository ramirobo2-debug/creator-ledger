直近の売れ方といまの在庫から、作り置きする数を決める

公開日: 2026-11-13

「売れる時期の前に、どの作品をいくつ作っておけばいい?」は、感覚で決めると、売れる作品が足りなくなったり、売れない作品が残ったりしがちです。作り置きの数は、直近の売れ方といまの在庫から逆に数えると、作品ごとにはっきり決まります。

この記事では、作品ごとの販売数と在庫から「あと何個作っておけばよいか」を式で出す方法を説明します。

考え方: 1日あたりの売れ方 → 見込み → 作り足す数

  1. 1日あたりの販売 = 直近の販売数 ÷ その日数(例: 90日で18個なら 0.2個)
  2. 見込みの販売数 = 1日あたり × 作り置きする日数 × 季節の倍率 × (1 + 予備の割合)
  3. 作り足す数 = 見込み − いまの在庫(小数は切り上げ、マイナスなら 0)

直近の販売数は、売上の記録から作品ごとに数えます。販売記録から在庫を減らしていく表は、販売記録から在庫を減らす記事で説明しています。季節の倍率と予備の決め方は、12月の倍率と予備の記事にまとめました。

表の作り方

「設定」のシートに、B2 作り置きする日数・B3 季節の倍率・B4 予備の割合を入れます。「作品」のシートは1行1作品で、A 作品・B 直近の販売数・C その日数・D いまの在庫・E 1個作る時間(分)・F 1個の原価・G この作品だけの倍率(空なら設定の倍率)を入れます。

H2(1日あたりの販売): =B2/C2
I2(見込みの販売数):   =H2*設定!$B$2*IF(ISNUMBER(G2),G2,設定!$B$3)*(1+N(設定!$B$4))
J2(作り足す数):       =MAX(0,ROUNDUP(ROUND(I2-D2,6),0))
K2(作る時間):         =J2*E2/60
L2(材料費):           =J2*F2
  • ROUND(…,6) は、割り算でできる小さな誤差で、ちょうど 7 のはずが 7.0000000001 になり、切り上げで 8 になるのを防ぐためです
  • MAX(0,…) で、在庫が見込みより多い作品は 0 にします
  • 予備の割合は 10% のように数として入れます(N() は空も文字も 0 にするので、文字で入っていると予備なしになります)
  • 実際に使う表では、販売数・日数・在庫のどれかが空や文字の行で #DIV/0! や #VALUE! が出ないよう、H 列を「入力がそろっているときだけ」計算し、I 列から先は前の列が数のときだけ計算する形(IF(ISNUMBER(...),…,""))にしています

例: 12月の1か月分を、いつもの1.5倍・予備10%で

作り置きする日数 30日、倍率 1.5、予備 10% とします。ヘアゴムはギフトでよく出るので、この作品だけ倍率を 2 にしました(数字は説明のための架空のものです)。

作品 直近の販売 1日あたり 見込み 在庫 作り足す数
レジンのピアス 90日で18個 0.20 9.9 3 7個
ビーズのネックレス 90日で6個 0.07 3.3 4 0個(足りている)
布のヘアゴム 90日で45個 0.50 33.0 0 33個(在庫切れ)
刺しゅうブローチ 90日で0個 0.00 0.0 5 0個(様子見)

ピアスは 0.2 × 30 × 1.5 × 1.1 = 9.9 個売れる見込みで、在庫が3個あるので、9.9 − 3 = 6.9 を切り上げて 7個です。合計で40個・作る時間 15.7時間・材料費 7,400円になりました。

数を見るときの注意

  • 直近の日数は長めにとる: 30日だと、たまたま売れた週に引っぱられます。90日くらいで見ると、ならした売れ方になります。ただし、去年の12月のように時期で売れ方が変わる場合は、それを倍率で足します
  • 出た数は「売れ方が同じように続いたら」の目安: 売れる数を約束するものではありません。新作や、特集に載った直後の作品は、直近の数が当てになりにくいので、少なめに作って様子を見ます
  • 売れていない作品は作り足さない: 直近の販売が 0 の作品は、見込みも 0 になります。在庫が残っているなら、まず値段や写真を見直す合図です(しばらく売れていない作品を見つける記事)

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。
