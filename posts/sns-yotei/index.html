SNS の投稿予定を表で管理する|「遅れ」「今日」を色で出し、最後に投稿してからの日数を MAXIFS で

公開日: 2026-11-11

「新作が出たら投稿しよう」「イベントの1週間前に告知しよう」と決めていても、制作や発送に追われていると、気づけば予定の日を過ぎていた、ということが起きます。SNS ごとに「最後にいつ投稿したか」も、いくつも使っていると覚えきれません。

この記事では、投稿の予定日と投稿した日を1行ずつ書き、状態(投稿済み・今日・遅れ・予定)を式で出して色をつけ、SNS ごとに最後に投稿した日・たった日数・次の予定日を出す表を作ります。

予定日と投稿した日を、同じ行に書く

投稿したい内容を思いついたら、予定日・SNS・種類・内容のメモを書いて、1行の「予定」にしておきます。投稿したら、同じ行の「投稿した日」を埋めます。予定と実績を別の表にしないので、「予定していたのに出していない投稿」が残っている行としてそのまま見えます。

反応の数(いいね・保存など)も同じ行に書けば、反応を種類別・曜日別に比べる記事の集計にそのまま使えます。

状態を式で出して、色をつける

N2(状態): =IF($B2<>"","投稿済み",IF(NOT(ISNUMBER($A2)),"",IF($A2=TODAY(),"今日",IF($A2<TODAY(),"遅れ","予定"))))
  • 投稿した日が入っていれば「投稿済み」です。予定日より何日遅れて投稿しても、投稿した時点で「投稿済み」になります
  • 投稿した日が空で、予定日が今日なら「今日」、過ぎていれば「遅れ」、まだ先なら「予定」です
  • 予定日が日付でない(文字が入っているなど)ときは空にします。ISNUMBER で日付かどうかを見ています

色は条件付き書式でつけます。範囲を状態の列(N2:N2001)にして、「数式を使用して…」で次の式を入れ、それぞれ色を選びます。

$N2="遅れ"   → オレンジ(予定日の列 A2:A2001 にも同じ式でつけると、どの日が遅れているかが目立ちます)
$N2="今日"   → 青

この画面は 2026年11月11日に開いたときのものです。11/8 の再入荷の告知はまだ投稿していないので「遅れ」になっています。TODAY() を使っているので、ファイルを開いた日によって、「予定」が「今日」に、「今日」が「遅れ」に変わっていきます。

予定日を過ぎたら必ず投稿しなければいけないわけではありません。出さないと決めた予定は、行を消すか、予定日を空にしておくと「遅れ」から外れます(予定日を空にした行は状態も空になります)。

SNS ごとに、最後に投稿した日・たった日数・次の予定日

SNS 別の表に3つの列を足します。

J2(最後に投稿した日): =IF(COUNTIFS(投稿!$C$2:$C$2001,$A2,投稿!$B$2:$B$2001,"<>")=0,"",MAXIFS(投稿!$B$2:$B$2001,投稿!$C$2:$C$2001,$A2))
K2(たった日数):       =IF(J2="","",TODAY()-J2)
L2(次の予定日):       =IF(COUNTIFS(投稿!$C$2:$C$2001,$A2,投稿!$B$2:$B$2001,"",投稿!$A$2:$A$2001,">0")=0,"",MINIFS(投稿!$A$2:$A$2001,投稿!$C$2:$C$2001,$A2,投稿!$B$2:$B$2001,"",投稿!$A$2:$A$2001,">0"))
  • 最後に投稿した日は、その SNS の行の「投稿した日」のいちばん新しい日付です。MAXIFS で出します
  • 次の予定日は、まだ投稿していない行の予定日のうち、いちばん早い日です。MINIFS で出します。遅れている予定があれば、その日が出ます
  • 予定日の条件 ">0" は、予定日を空にした行を外すためのものです。これが無いと、ソフトによっては空の予定日が 0 として最小の値に選ばれ、次の予定日がおかしな日付になります。この例でも、予定日を空にした Instagram の行を表の外に1行足して、次の予定日が 11/8 のままになることを確かめました
  • どちらも、当てはまる行が1つも無いと 0 を返すので、COUNTIFS で数えて空にしています(0 を日付にすると 1899年や1900年の日付になります)
  • J と L のセルは、表示形式を日付にします

この例では、Instagram は最後の投稿から10日たっていて、次の予定日の 11/8 はもう過ぎています。X は7日前に投稿したきり、次の予定がありません。Threads はまだ1回も投稿していなくて、今日が最初の予定です。「次の予定日が空の SNS」は、予定を足し忘れている SNS の目印になります。

たった日数に色をつけたいときは、K の列に条件付き書式で AND(ISNUMBER($K2),$K2>=14) のような式を入れます。何日あいたら気にするかは、SNS ごとの投稿のペースに合わせて決めてください。

MAXIFS・MINIFS は Excel 2019 以降・Microsoft 365・Google スプレッドシート・LibreOffice で使えます。MAXIFS の代わりに古い Excel でも動く書き方は、しばらく売れていない作品を見つける記事の最後に書いています(MINIFS は同じ形では置き換えられないので、古い Excel では次の予定日の列を省いてください)。

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、設定(SNS・種類)・投稿・SNS別・種類別・曜日別をまとめたテンプレートで作りました。状態と色の設定は入っていますが、最後に投稿した日・たった日数・次の予定日の3列は入っていないので、使うときはこの記事の式を SNS 別のシートの右に足してください。表を一から作る時間を省きたい方は、ハンドメイド作家の SNS 投稿 予定・反応の記録シートもご覧ください。
