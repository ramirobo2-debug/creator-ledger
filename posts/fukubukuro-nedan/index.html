福袋の値段を、単品の合計と赤字にならない下限から決める

公開日: 2026-11-13

年末年始の福袋は、「単品の合計より安い」ことが前提の売り方です。でも、どこまで安くしてよいかは、福袋に入れる作品が、ふだん売れているものか、売れ残りかで変わります。

  • ふだん売れている作品を入れる → 単品で売ったときの利益と比べる(単品より減らない値段)
  • しばらく売れていない作品を入れる → この先も単品では売れる見込みが小さいと見るなら、赤字にならないか(利益が 0円以上か)で見る

この2つの境目を出しておくと、福袋の値段を決めやすくなります。

2つの境目の出し方

1回の発送の費用 = 送料の持ち出し + 梱包資材の費用 とします。

単品と同じ利益になる下限 = (単品で売ったときの利益 + 原価の合計 + 1回の発送の費用)÷(1 − 手数料の割合)
赤字にならない下限       = (原価の合計 + 1回の発送の費用)÷(1 − 手数料の割合)

単品で売ったときの利益は、1個ずつ別々に売って送ったときの利益です(式はまとめ割の上限を出す記事)。表では、福袋も「セット」の1行として入れると、単品と同じ利益になる下限と、「セットは赤字」の判定が出ます。

例: 5点入りの福袋

単品の合計 6,000円・原価の合計 1,800円の5点を、1つの福袋にします。手数料 10%、送料の持ち出し 200円、梱包資材 60円です(数字は説明のための架空のものです)。

福袋の値段 福袋の利益 単品で売ったとき(2,300円)との差 判定
2,200円(約63%引き) −80円 −2,380円 セットは赤字
3,000円(半額) 640円 −1,660円 単品より減る
4,800円(20%引き) 2,260円 −40円 単品より減る
  • 単品と同じ利益になる下限は 4,845円(割引できる上限は約19%)。ふだん売れている作品だけで作るなら、20%引きでもわずかに減ります
  • 赤字にならない下限は (1,800 + 260)÷ 0.9 ≒ 2,289円。売れ残りの作品で作るなら、2,289円より上なら、福袋が1つ売れるたびに利益が出ます。2,200円にすると、売れても 80円の持ち出しです

「半額の福袋」は、ふだん売れている作品で作ると単品より 1,660円減ります。この先も単品では売れる見込みが小さい作品で作るなら、原価を引いても 640円の利益が出て、在庫も減ります(材料費をもう払ってあるなら、売れたときに入るお金は 640円より多くなります)。同じ 3,000円でも、中身によって良し悪しが変わります。

値段を決める手順

  1. 入れる作品の単品の価格の合計と原価の合計を出す
  2. ふだん売れている作品が多いなら、単品と同じ利益になる下限の近くで値段を決める
  3. 売れ残りが多いなら、赤字にならない下限より上で、お得感が出る値段にする
  4. 両方が混ざるときは、ふだん売れている作品の分だけ単品の利益を足し、売れ残りの分は 0円として下限を出し直す

しばらく売れていない作品の見つけ方は売れていない作品を MAXIFS で見つける記事、作り置きの残りの数は作り置きする数の記事で出し方を説明しています。

数を見るときの注意

  • 福袋は箱や袋が大きくなりやすく、送料が1サイズ上がることがあります。福袋の袋やおまけなど、福袋のときだけかかる費用も同じです。これらを原価の合計に足すと、単品の利益からも同じだけ引かれて、単品との比べには効きません。赤字にならない下限は原価に足して出し、単品と同じ利益になる下限には「福袋だけの費用 ÷(1 − 手数料の割合)」を足して見ます
  • 受け取った送料にも販売手数料がかかる出品先では、その手数料の分も送料の持ち出しに足して入れます
  • ここでの利益は1つあたりで、道具代・出店料などの固定費は引いていません

作った表を、そのまま使いたい方へ

この記事の表は、セット・まとめ割・福袋を1行ずつ入れて、単品と比べた利益と下限の価格、得か減るか赤字かの判定まで出すテンプレートで作りました。表を一から作る時間を省きたい方は、ハンドメイド セット販売・まとめ割の利益の試算シートもご覧ください。

関連記事

  • セット販売・まとめ割は、何%まで割り引いても単品と同じ利益が残るかを出す
  • 送料の持ち出しが大きいほど、まとめ割を大きくできる理由と割引の上限の出し方
