SNS 投稿の反応を記録して、種類別・曜日別に平均で比べる|AVERAGEIFS と反応率の出し方

公開日: 2026-11-11

作品の写真を Instagram や X に投稿していると、「制作過程の投稿と完成品の投稿、どちらが見てもらえているのか」「何曜日に出すといいのか」が気になってきます。アプリの分析画面は投稿1件ずつの数字が中心で、種類ごと・曜日ごとにまとめて比べるには、自分で記録をつけるのが近道です。

この記事では、投稿を1行ずつ記録して、反応の合計と反応率を式で出し、AVERAGEIFS で SNS 別・種類別・曜日別の平均を出す表を作ります。

投稿を1行ずつ記録する

記録の表には、次の列を作ります。

  • 予定日/投稿した日/SNS/種類(新作紹介・制作過程・イベント告知など)/作品・内容のメモ
  • いいね/保存/コメント/表示(リーチ)/問い合わせ・売れた

数字はアプリに出る数を書き写します。投稿した直後は数が伸びている途中なので、「投稿から3日後に書く」のように、書き写す時期をそろえておくと比べやすくなります。

SNS と種類は、設定のシートに一覧を作って、入力規則(プルダウン)で選ぶようにします。「新作」「新作紹介」のように書き方が分かれると、別の種類として集計されてしまうためです。作品名の打ちまちがいを防ぐやり方は、入力のまちがいを色で知らせる記事と同じです。

反応の合計・反応率・曜日を式で出す

L2(反応の合計): =IF(OR($B2="",COUNT($F2:$H2)=0),"",SUM($F2:$H2))
M2(反応率):     =IF(OR($L2="",NOT(ISNUMBER($I2))),"",IF($I2<=0,"",$L2/$I2))
O2(曜日):       =IF(ISNUMBER($B2),CHOOSE(WEEKDAY($B2),"日","月","火","水","木","金","土"),IF(ISNUMBER($A2),CHOOSE(WEEKDAY($A2),"日","月","火","水","木","金","土"),""))
  • 反応の合計は、いいね・保存・コメントを足したものです。まだ投稿していない行(投稿した日が空)は空にします
  • 反応率は、反応の合計 ÷ 表示です。表示が0や空のときは割り算をしないで空にします
  • 曜日は、投稿した日があればその日、まだ投稿していなければ予定日から出します。こうしておくと、曜日別の表で「これからの予定」も曜日ごとに数えられます
  • WEEKDAY で1(日)〜7(土)の数を出し、CHOOSE で文字にします。Excel の日本語版なら TEXT(B2,"aaa") でも出ますが、Google スプレッドシートや LibreOffice では書式の書き方が違うので、どれでも同じに動く CHOOSE にしています

X の 11/4 の行は、保存の数が出ないので空にしています。0 と書かずに空にしておくのがポイントで、次の平均の式で「数が無い投稿」として外せます。

AVERAGEIFS で、種類ごとの平均を出す

種類別の表では、種類の名前を左に並べ、AVERAGEIFS で平均を出します。

B2(投稿した数): =COUNTIFS(投稿!$D$2:$D$2001,$A2,投稿!$B$2:$B$2001,"<>")
D2(平均いいね): =IFERROR(AVERAGEIFS(投稿!$F$2:$F$2001,投稿!$D$2:$D$2001,$A2,投稿!$B$2:$B$2001,"<>",投稿!$F$2:$F$2001,"<>"),"-")
H2(平均の反応率): =IFERROR(AVERAGEIFS(投稿!$M$2:$M$2001,投稿!$D$2:$D$2001,$A2,投稿!$B$2:$B$2001,"<>",投稿!$I$2:$I$2001,">0",投稿!$L$2:$L$2001,"<>"),"-")
  • 条件の 投稿した日,"<>" で、まだ投稿していない予定の行を平均から外します
  • いいね,"<>" で、数を書いていない行を外します。空の行を 0 として平均に入れると、平均が下がってしまいます
  • まだ1件も投稿していない種類は、AVERAGEIFS が #DIV/0! になるので、IFERROR で「-」にします

この例では、反応率は制作過程 5.5%、新作紹介 5.0% でほぼ同じですが、問い合わせ・売れた数は新作紹介が2件でした。反応の多さと売れることは別なので、「問い合わせ・売れた」の列も並べて見ておくと判断しやすくなります。

保存の平均は、数が書いてある投稿だけで出しています。新作紹介の保存は Instagram の1件(12)だけなので 12.0 です。

反応率は「平均」と「合計 ÷ 合計」で少しずれる

平均の反応率は、投稿1件ずつの反応率を平均したものです。Instagram の3件(7.7%・7.9%・5.7%)の平均は 7.1% になります。

一方、3件の反応の合計を表示の合計で割ると、190 ÷ 2,620 = 7.3% です。表示の多い投稿の反応率が強く効くので、少しずれます。どちらがまちがいということはありません。「1件の投稿として、ふつうどのくらい反応があるか」を見たいなら平均、「その期間の表示の合計に対して、反応がどのくらいの数あったか」を見たいなら合計 ÷ 合計です。

なお、ここでの反応率は「反応した人の割合」ではありません。いいね・保存・コメントは同じ人が重ねてすることもあるので、反応の件数 ÷ 表示の数、という比率です。表示の欄には、SNS のアプリに出る数のうち、表示回数かリーチ(見た人の数)のどちらか一方を決めて、毎回同じものを書いてください。

合計 ÷ 合計で出すときは、

=IFERROR(SUMIFS(投稿!$L$2:$L$2001,投稿!$C$2:$C$2001,$A2,投稿!$B$2:$B$2001,"<>",投稿!$I$2:$I$2001,">0",投稿!$L$2:$L$2001,"<>")/SUMIFS(投稿!$I$2:$I$2001,投稿!$C$2:$C$2001,$A2,投稿!$B$2:$B$2001,"<>",投稿!$I$2:$I$2001,">0",投稿!$L$2:$L$2001,"<>"),"-")

のように、分子(反応の合計)と分母(表示)に同じ条件をつけて、同じ行だけを足してから割ります。条件がずれると、表示はあるのに反応を書いていない行が分母にだけ入る、といったずれが起きます。この式でも、Instagram は 7.3%、X は 40 ÷ 1,550 = 2.6% になりました(平均の反応率は 2.7%)。

曜日ごとに比べるときの注意

曜日別の表は、種類別と同じ式で、条件の列を曜日の列に変えるだけです。

この例では木曜の平均いいねが 55.0 でいちばん多く見えますが、木曜の2件はどちらも Instagram で、日曜・水曜には X の投稿が入っています。SNS によって反応の数の桁が違うので、曜日の差に見えて、実は SNS の差ということがあります。

曜日を比べるときは、AVERAGEIFS に 投稿!$C$2:$C$2001,"(例)Instagram" のように SNS の条件を1つ足して、同じ SNS の中で比べてください。また、1つの曜日に数件しか無いうちは、たまたまの差が大きく出ます。各曜日に5件以上たまってから見るくらいが目安です。

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、設定(SNS・種類)・投稿・SNS別・種類別・曜日別をまとめたテンプレートで作りました。予定日を過ぎた投稿をオレンジにする設定や、数の欄の入力まちがいを赤で知らせる設定も入っています。予定の管理のしかたはSNS の投稿予定を管理する記事で説明しています。表を一から作る時間を省きたい方は、ハンドメイド作家の SNS 投稿 予定・反応の記録シートもご覧ください。
