お客さまごとの購入回数で、リピーターを見分ける|COUNTIFS と最後の連絡からの日数

公開日: 2026-11-11

何度も買ってくれているお客さまが誰か、すぐに思い出せるでしょうか。販売サービスが分かれていると、同じ方が minne でもイベントでも買ってくれていることに気づきにくくなります。

この記事では、お客さまとの連絡の記録から、お客さまごとの購入の回数・合計・リピーターかどうか・最後の連絡からの日数・評価の平均を式で出す方法を説明します。

連絡の記録のつけ方と、返信忘れの知らせ方は、返信忘れを式で知らせる記事で説明しています。この記事はその表の続きです。

お客さまの表に、購入の回数と合計を出す

お客さまの表には、呼び名と好みのメモだけを書きます。残りの列は、対応の記録(お客さま・購入・金額・評価の列)から式で集めます。

C2(連絡の件数): =IF($A2="","",COUNTIFS(対応!$B$2:$B$3001,$A2))
D2(購入の回数): =IF($A2="","",COUNTIFS(対応!$B$2:$B$3001,$A2,対応!$H$2:$H$3001,"はい"))
E2(購入の合計): =IF($A2="","",SUMIFS(対応!$I$2:$I$3001,対応!$B$2:$B$3001,$A2,対応!$H$2:$H$3001,"はい"))
F2(区分):       =IF($A2="","",IF($D2>=2,"リピーター",IF($D2=1,"1回購入","まだ購入なし")))
  • 購入は、対応の行の「購入」の列に「はい」と金額を書いたものだけを数えます。1回の購入は1行にだけ書きます(問い合わせの行と、届いたあとのお礼の行の両方に書くと、2回と数えます)
  • この例の Aさん は、minne で1回、イベントで1回買っているので、窓口が違ってもリピーターになります。窓口ごとに名前を変えて書くと別の人として数えるので、同じ方だと確かめられたら1つの呼び名にそろえます。反対に、別の方が同じニックネームのときは1人として合わさるので、「Aさん(minne)」のように重ならない呼び名を付けて分けます
  • リピーターの境目は2回にしています。3回以上をリピーターにしたいときは、$D2>=2 を $D2>=3 に変え、2回の人の分かれ目も足します(例: IF($D2>=3,"リピーター",IF($D2>=1,"購入あり","まだ購入なし")))。2 を 3 に変えるだけだと、2回の人が「まだ購入なし」になります

最後の連絡からの日数と、評価の平均

G2(最後の連絡):
=IF($A2="","",IF(SUMPRODUCT(MAX((対応!$B$2:$B$3001=$A2)*対応!$N$2:$N$3001))=0,"",
 SUMPRODUCT(MAX((対応!$B$2:$B$3001=$A2)*対応!$N$2:$N$3001))))
H2(最後の連絡からの日数): =IF(OR($A2="",$G2=""),"",TODAY()-$G2)
I2(評価の平均):
=IF($A2="","",IFERROR(AVERAGEIFS(対応!$J$2:$J$3001,対応!$B$2:$B$3001,$A2,
 対応!$J$2:$J$3001,">=1",対応!$J$2:$J$3001,"<=5"),""))
  • 対応の N 列は、受けた日が日付ならその日、そうでなければ 0 を入れておく作業用の列です(=IF(ISNUMBER($A2),$A2,0))。文字の入ったセルを掛け算に使わないようにするためです
  • G 列は、お客さまが一致する行だけ日付が残るように掛け算し、その最大を取っています。MAXIFS が使える Excel 2019 以降や Google スプレッドシートなら =MAXIFS(対応!$A$2:$A$3001,対応!$B$2:$B$3001,$A2) でも同じ日付が出ます(連絡が1件も無いと 0 になるので、外側の IF で 0 を空にする形は残します)
  • 評価は 1〜5 の数だけを平均します。打ちまちがいの 0 や 50 が平均を動かさないようにするためです

最後の連絡からの日数が長いリピーターは、新作のお知らせを送る相手の候補になります(各サービスのメッセージの決まりの範囲で送ります)。

種類別に、購入を書いた件数を見る

種類別のシートでは、連絡の種類ごとに件数と、その行に書いた購入の件数・金額を出します。その連絡が購入のきっかけだったかまでは式では分からないので、目安として見ます。

この例では、作品の問い合わせ3件のうち2件の行に購入を書いています。同じ質問が何度も来ているのに購入が少ないときは、内容のメモを見返して、説明文に答えを先に書いておく、といった直し方を考える目安になります(どの作品の問い合わせかは、内容のメモに作品名を書いておくと追えます)。購入を「どの行に書くか」で数え方が変わるので、たとえば「購入につながった問い合わせの行に書く」のように、書く場所を決めておきます。

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、設定・お客さま・対応・窓口別・種類別をまとめたテンプレートで作りました。表を一から作る時間を省きたい方は、ハンドメイド作家のお客さま対応の記録シートもご覧ください。
