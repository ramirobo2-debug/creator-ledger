送料無料まであと何円かと、まとめ買いで1個あたりがいくら下がるかを出す

公開日: 2026-11-12

ネットの店で材料を買うとき、「あと少しで送料無料」という表示を見て、つい何かを足してしまうことがあります。足したほうが本当に得かどうかは、送料無料まであと何円かと、足したあとの1個あたりの値段を並べると、すぐにわかります。

この記事では、比較の表に「送料無料まで」の列を足し、同じ店で袋の数を変えた行と比べて、まとめ買いの得と損を式で出す方法を説明します。表の作り方そのものは、材料の仕入れ先を送料込みの1個あたりで比べる記事で説明しています。

送料無料まであと何円かを出す

品代(1袋の値段 × 袋の数)が、送料無料になる金額に届いていなければ、その差を出します。

O2(送料無料まで): =IF(AND(ISNUMBER($I2),N($G2)>0),IF($I2<$G2,$G2-$I2,""),"")
  • 送料無料の金額が空の店(いつも送料がかかる店・いつも無料の店)は、空のままにします
  • 品代が無料の金額以上なら、もう送料無料なので空にします

さらに、あと何円が送料より少ない行をオレンジにします(条件付き書式で、O 列が数で、O2 < F2 のとき)。「買い足す検討をしてよい」という目印です。

ただし、オレンジでも支払いが減るとは限りません。実際に足す商品の値段は、あと何円ちょうどにはならないからです。支払いが減るのは、実際に足す金額が送料より少ないときだけです(同じなら支払いは変わりません)。送料より多く足すときは、足した分を使い切れるか、近いうちに買う予定のものかで決めます。

例: ピアス金具を3袋か4袋か

1袋 480円・10ペア入りのピアス金具を、送料 250円・1,500円以上で送料無料の店で買う場合です。

  • 3袋: 品代 1,440円 + 送料 250円 = 1,690円。30ペアで1ペアあたり 56.33円。送料無料まであと 60円(送料 250円より少ないのでオレンジ)
  • 4袋: 品代 1,920円で送料無料 = 1,920円。40ペアで1ペアあたり 48.00円

あと 60円でも、足せるのは1袋 480円なので、支払いは 230円増えます(480円足して、送料 250円が要らなくなる)。そのかわり10ペア多く手に入り、1ペアあたりは 8.33円下がります。ピアス金具のようにいつも使う材料なら、4袋のほうが得です。

例: レジン液を2本か4本か

1本 1,280円のレジン液を、送料 520円・3,980円以上で送料無料の店で買う場合です。

  • 2本: 2,560円 + 520円 = 3,080円。1本あたり 1,540円。送料無料まであと 1,420円(送料より多いので色はつきません)
  • 4本: 5,120円で送料無料。1本あたり 1,280円
  • 別の店B(送料無料・1本 1,450円)で2本: 2,900円。1本あたり 1,450円

4本買えば1本あたりは一番安くなりますが、支払いは 2,900円から 5,120円に増えます。3本(3,840円)では無料の線に届かないので、得になるのは4本からです。

ここで足す前に確かめたいのが、その数を使い切れるかです。レジン液のように使える期間がある材料や、流行りの色のパーツは、使い切れずに残った分がそのまま損になります。買い足す数の目安は、材料の在庫と買い足しの時期を出す記事の「1か月に使う数」から決めると外れにくくなります。

足すかどうかの決め方

  1. オレンジの行(あと何円 < 送料): 近いうちに使う予定の材料で、足す金額が送料より少なければ、支払いも減ります。同じ材料を足すなら、袋の数を増やした行を作って1個あたりを比べる
  2. 色のない行(あと何円 ≥ 送料): 予定のないものを足すと、送料を払うより支払いが増えます。使い切れる見込みがあるときだけ、まとめ買いの行を作って比べる
  3. ほかの材料も同じ店で買うとき: 送料無料の判定は、ふつう注文全体の品代で決まります。この表は1行を1回の注文として計算しているので、同じ店でまとめて買うなら、その店の品代を足し合わせてあと何円かを見ます
  4. 別の店のほうが安いとき: 送料無料にするために高い店で足すより、最安の店で必要な分だけ買うほうが安いことがあります。「最安」の列で確かめます

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、送料無料まであと何円かと最安を出すテンプレートで作りました(送料より少ない金額で届く行をオレンジにする書式も入っています)。表を一から作る時間を省きたい方は、ハンドメイド 材料の仕入れ先・価格比較シートもご覧ください。
