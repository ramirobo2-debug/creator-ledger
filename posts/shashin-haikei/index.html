作品写真の撮り方を記録して、背景ごとに「使えた割合」と反応率を比べる

公開日: 2026-11-12

作品写真は、背景や光を変えると印象が大きく変わります。ただ、撮るたびに設定を変えていると、「前にうまく撮れたのはどの背景だったか」「どの写真がよく見られたか」が分からなくなりがちです。

この記事では、撮影ごとに背景・光・撮った枚数・使った枚数・出品したあとの閲覧数とお気に入りを1行に記録し、SUMIFS で背景ごとに「使えた割合」と「反応率」を出して比べる方法を説明します。

撮影ごとに1行で記録する

撮影のシートには、1回の撮影を1行で書きます。

  • 撮った枚数・使った枚数: その撮影で撮った枚数と、出品やSNS に実際に使った枚数
  • 閲覧数・お気に入り・売れた数: 出品先の管理画面の数字を書き写します。出品してから書き写すまでの日数(たとえば7日後)をそろえておくと、行どうしを比べやすくなります。日数は設定のメモに残しておきます
  • 1つの出品に、撮影の行は1つ: 閲覧数は作品ページ全体の数字です。同じ作品を背景を変えて何回か撮り、写真をまぜて1つのページに出したときは、どの撮影の数字か分けられないので、閲覧の欄はいちばん多く使った撮影の行にだけ書き、ほかの行は空にしておきます。撮り直して写真を入れ替えたときは、入れ替えた日からの数字を新しい行に書きます
  • 設定のメモ: 「明るさ+0.7・真上から」のように、同じ写真をもう一度撮るための手がかりを書きます

背景と光は、設定のシートに書いた名前から選びます。名前の書き方が1文字でも違うと別の背景として数えられるので、選んで入れる形にしておくと集計がずれません。

行ごとの割合は、空の欄や 0 で割らないようにした式で出しています。

M2(使えた割合): =IF(AND(ISNUMBER($G2),$G2>0,ISNUMBER($H2)),$H2/$G2,"")
N2(反応率):     =IF(AND(ISNUMBER($J2),$J2>0,ISNUMBER($K2)),$K2/$J2,"")

反応率は「お気に入り ÷ 閲覧数」です。まだ出品していない7行目は、閲覧数が空なので反応率も空になります。

背景ごとに SUMIFS で足す

背景別のシートは、A 列に設定のシートの背景の名前を並べ、その背景の行だけを足します。

B2(撮った回数):   =COUNTIFS(撮影!$C$2:$C$2001,$A2)
C2(撮った枚数):   =SUMIFS(撮影!$G$2:$G$2001,撮影!$C$2:$C$2001,$A2,撮影!$H$2:$H$2001,">=0")
D2(使った枚数):   =SUMIFS(撮影!$H$2:$H$2001,撮影!$C$2:$C$2001,$A2,撮影!$G$2:$G$2001,">0")
E2(使えた割合):   =IF(N($C2)=0,"",$D2/$C2)
G2(閲覧の合計):   =SUMIFS(撮影!$J$2:$J$2001,撮影!$C$2:$C$2001,$A2,撮影!$J$2:$J$2001,">0",撮影!$K$2:$K$2001,">=0")
H2(お気に入りの合計): 上の式の、合計する列を 撮影!$K$2:$K$2001 にする
I2(反応率):       =IF(N($G2)=0,"",$H2/$G2)

(テンプレートでは、A 列が空の行を空にする IF($A2="","",…) で全体を包んでいます。)

ポイントは、撮った枚数と使った枚数、閲覧とお気に入りを、それぞれ両方入った行だけで足すことです。撮った枚数だけ書いて使った枚数を書き忘れた行が分母に入ると、使えた割合が実際より低く出ます。そこで、撮った枚数は「使った枚数が 0 以上の行」、閲覧は「お気に入りが 0 以上の行」だけを足しています(条件の ">=0" は、数が入っている行だけに当てはまり、空の行は外れます)。

この例では、次のことが読み取れます。

  • 白い板は、使えた割合 21.5%・反応率 8.6% のどちらもいちばん高い(緑の色は、反応率がいちばん高い背景につきます)
  • 麻の布は、使えた割合は 19.0% と白い板に近いが、反応率は 7.1%。撮りやすさと、見た人の反応は別の数字です
  • 木のトレーは1回しか撮っていないので、まだ比べる材料が足りません。回数が少ない背景は、数回撮ってから判断します

使えた割合は「撮影のしやすさ」、反応率は「見た人の反応」の目安です。両方が高い背景を基本にして、ほかの背景は数回ずつ試す、という使い方ができます。

比べるときの注意

  • 反応率は、作品そのものの人気や、出品した時期にも左右されます。背景だけの差とは言い切れないので、同じくらいの作品で数回ずつ試してから比べるのが確かです
  • 閲覧数の数え方は、出品先(minne・Creema・Instagram など)ごとに違います。出品先が混ざった合計で比べると、閲覧の多い出品先の数字に引っぱられます。出品先をそろえて比べる方法は、出品先ごとに分けて反応率を比べる記事で説明しています
  • 光の当て方ごとの比べ方と、「1行ずつの反応率の平均」との違いは、光の当て方ごとに反応率を比べる記事で説明しています

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。SNS の投稿の反応を種類別に比べる方法は、SNS投稿の反応を種類別と曜日別に比べる記事にあります。

作った表を、そのまま使いたい方へ

この記事の表は、設定・撮影・背景別・光別をまとめたテンプレートで作りました。表を一から作る時間を省きたい方は、ハンドメイド作品写真の撮影設定と反応の記録シートもご覧ください。
