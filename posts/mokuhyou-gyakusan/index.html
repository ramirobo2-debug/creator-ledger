月に残したい手取りから、作品ごとに月に何個売ればよいかを逆算する

公開日: 2026-11-13

「ハンドメイドで月に5万円」と目標を立てても、売上で5万円なのか、手元に残る額で5万円なのかで、売る数はまったく変わります。目標を手元に残したい額で決めて、そこから作品ごとに月に何個売ればよいかを逆に数えると、毎月の動き方が具体的になります。

この記事では、作品ごとの1個の利益と「目標のうちこの作品で稼ぐ割合」から、月に売る数と売上を式で出す方法を説明します。

考え方: 手取り → 必要な利益 → 作品ごとの数

  1. 必要な利益 = 月に残したい手取り + 月の固定費(出店料・ショップの月額・道具のサブスクなど)
  2. 1個の利益 = 販売価格 − 1個の原価 − 販売価格 × 手数料の率 − 1個あたりの送料の持ち出し
  3. この作品で稼ぐ利益 = 必要な利益 × 割合
  4. 月に売る数 = この作品で稼ぐ利益 ÷ 1個の利益(小数は切り上げ)

固定費は売れた数に関係なく出ていくので、手取りに足してから割り振ります。1個の原価の出し方は、ハンドメイド作品の原価の出し方で説明しています。

表の作り方

「目標」のシートの B2 に手取り、B3 に固定費を入れ、B7 で必要な利益を出します。

目標!B7(必要な利益): =IF(AND(ISNUMBER(B2),ISNUMBER(B3)),B2+B3,"")

「作品」のシートは1行1作品で、A 作品・B 販売価格・C 1個の原価・D 手数料の率・E 送料の持ち出し・F 割合・G 1個作る時間(分)を入れます。H 列から先が式です。

H2(1個の利益):        =B2-C2-B2*D2-N(E2)
J2(この作品で稼ぐ利益): =目標!$B$7*F2
K2(月に売る数):        =ROUNDUP(J2/H2,0)
L2(売上):             =K2*B2
N2(1週あたりの数):     =ROUNDUP(K2*7/30,0)
  • 送料をお客さまからいただいている作品は、E 列を空か 0 にします(N() で空を 0 として扱います)
  • 1個の利益が 0 以下の作品は、何個売っても目標に近づかないので、数を出さずに赤にしておくと気づけます
  • 実際に使う表では、入力が欠けている行や1個の利益が 0 以下の行で #DIV/0! やマイナスの数が出ないよう、J 列を「H が正の数で、割合が入っているときだけ」計算し、K 列から先は J が数のときだけ計算する形(IF(ISNUMBER(...),…,""))にしています

例: 手取り5万円・固定費3,000円

必要な利益は 53,000円です。3つの作品に、5割・3割・2割で割り振ります(手数料はどれも10%とした架空の数字です)。

作品 価格 1個の利益 割合 稼ぐ利益 月に売る数 売上
レジンのピアス 1,800 1,270 50% 26,500 21個 37,800
ビーズのネックレス 2,800 1,920 30% 15,900 9個 25,200
布のヘアゴム 900 610 20% 10,600 18個 16,200

ピアスは 26,500 ÷ 1,270 = 20.9 なので、切り上げて 21個です。合計で月に48個・売上 79,200円。手取り5万円のために必要な売上は、5万円よりかなり多くなることがわかります。1週あたりにすると、ピアス5個・ネックレス3個・ヘアゴム5個が目安です。

割合の決め方と注意

  • 割合は合計を100%にする: 合計が 90% だと、残りの 10% の分が誰にも割り振られず、目標に届かない数が出ます。合計を別のセルで出し(=SUM(作品!F2:F101))、100% でなければ「割合の合計を100%にしてください」と出すようにしておくと安心です
  • 迷ったら、いま稼げている利益の比で分ける: 割合は「利益」の割合なので、売れた数の比ではなく、作品ごとの「売れた数 × 1個の利益」の比にします(1個の利益が作品ごとに違うため、数の比をそのまま使うと実績からずれます)。実績に近い割合のほうが、出た数が現実的になります。月ごとの売れ方は、売上を月別に集計する記事の表から拾えます
  • 出た数は「これだけ売れれば届く」目安: 売れる数を約束するものではありません。数が多すぎると感じたら、値段か割合か目標を見直す合図です

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

次は、この数を作る時間に直して、作業できる時間に収まるかを確かめます(目標の数を作るのに何時間かかるかを出す記事)。

作った表を、そのまま使いたい方へ

この記事の表は、月に残したい手取りから作品ごとの数・売上・作る時間まで出すテンプレートで作りました(割合の合計や入力の漏れを赤で知らせる書式も入っています)。表を一から作る時間を省きたい方は、ハンドメイド 売上目標の逆算シートもご覧ください。
