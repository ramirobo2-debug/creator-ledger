ハンドメイドのラッピングの原価を、資材費と作業時間で出す

公開日: 2026-11-12

12月が近づくと、「プレゼント用に包んでもらえますか」というご注文が増えます。ラッピングを無料にしている方も、100円・300円といただいている方もいると思いますが、その金額で本当に足りているかは、袋やリボンの代金と、包む時間を足してみないとわかりません。

この記事では、ラッピング1回を1行で記録して、資材費・作業の分・原価・1個あたりの原価・いただいたラッピング代との差を式で出す表を作ります。

1回のラッピングを1行で書く

ラッピングのシートには、次の列を用意します。

  • 日付・注文/作品・出品先・包み方・包んだ数
  • 受け取ったラッピング代(無料なら 0)
  • 使った資材と数(3種類まで。資材1・数、資材2・数、資材3・数)
  • 作業時間(分)

資材の1個あたりの値段は、設定のシートに「買った値段 ÷ 入っていた数」で出しておきます。ギフト袋20枚入り 300円なら 1枚 15円、リボン 10m 分 220円を 1m ずつ使うなら 1本 22円です(資材の値段の出し方は梱包資材の1個あたりの値段の記事と同じ考え方です)。

資材費・作業の分・原価・差の式

N2(資材費):
=IF(AND($G2<>"",ISNUMBER($H2)),IFERROR(VLOOKUP($G2,設定!$C$2:$F$31,4,FALSE)*$H2,0),0)
 + 資材2(I・J 列)・資材3(K・L 列)の同じ形
O2(作業の分):   =IF(AND(ISNUMBER($M2),N($M2)>=0),$M2/60*N(設定!$H$2),0)
P2(原価の合計): =N($N2)+N($O2)
Q2(1個あたり):  =IF(AND(ISNUMBER($P2),ISNUMBER($E2),N($E2)>0),$P2/$E2,"")
R2(差):         =IF(AND(ISNUMBER($F2),ISNUMBER($P2)),$F2-$P2,"")
  • テンプレートの N2〜P2 は、行が空のときは空になるように全体を IF で包んでいます。上の式は、計算の部分だけを抜き出したものです
  • 作業の分は「分 ÷ 60 × 時給」です。設定の H2 に自分の時給(例は 1,000 円)を入れます。時給を空にすると作業の分は 0 になり、資材費だけの原価になります
  • R 列がマイナスの行は、条件付き書式でオレンジにしています
  • 無料のときも、受け取ったラッピング代に 0 を入れます。空のままだと差が出ず、持ち出しの合計と回数から抜けてしまいます
  • IFERROR で、設定に無い資材名は 0 円になります。打ちまちがいがあると原価が少なく出るので、テンプレートでは設定に無い資材名や、資材と数の片方だけの欄を、条件付き書式で赤にしています。赤が残っているうちは、原価を確定した数字として使わないようにします

1行目のピアスは、無料ラッピングで、ギフト袋 15円・リボン 22円・シール 4円の資材費 41円に、5分の作業 83円を足して、原価は約 124円です。受け取ったラッピング代が 0 なので、差は −124円になります。

作業時間を入れる理由

資材費だけなら 41円で「無料でもたいしたことはない」と見えます。でも、包むのに5分かかっているなら、その5分は作品を作る時間から出ています。月に20回包めば 100分、時給 1,000円なら約 1,700円分です。

作業の分は、実際に払うお金ではありません。「ラッピングにこれだけの時間を使っている」ことを、お金の単位で見るための数字です。時給の考え方は作品ごとの時給を出す記事でも説明しています。

読み方の注意

  • 包んだ数で割る: 3点を1つの袋にまとめたのか、3つ別々に包んだのかで、1個あたりは大きく変わります。包んだ数には「包んだ袋・箱の数」を入れます
  • 作業時間は、だいたいでよい: ストップウォッチで測らなくても、5分・10分の単位で十分です。毎回入れることのほうが大切です
  • 資材は使った分だけ: ギフトボックス5個入り 550円を買っても、1回に使うのは 1個 110円分です。12月に向けて資材をいくつ買い足すかは、ラッピング資材を買い足す数の記事で出せます

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。ラッピング代を作品の値段に入れる考え方は、ハンドメイド作品の値段の決め方もあわせてご覧ください。

作った表を、そのまま使いたい方へ

この記事の表は、設定・ラッピング・包み方別・出品先別・資材別をまとめたテンプレートで作りました。表を一から作る時間を省きたい方は、ハンドメイド ラッピング・ギフト包装の原価記録シートもご覧ください。
