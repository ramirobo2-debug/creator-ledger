ハンドメイドの売上を販売先ごとに集計する|minne・Creema・イベントで手数料率が違うとき

公開日: 2026-11-11

ハンドメイドの作品を、minne や Creema などのサイト、自分のショップ、イベントの手売りと、いくつかの場所で売っていると、「どこでいくら売れて、手数料を引くといくら残ったか」が分かりにくくなります。販売先ごとに手数料率が違うからです。

この記事では、販売先の表に手数料率を書き、販売の記録の1行ごとに手数料を出して、販売先ごとの売上・手数料・利益を SUMIFS で集計する方法を、例の数字で説明します。

販売先の表に、手数料率を書く

まず、販売先と手数料率の表を作ります。

この表の率は、説明のための仮の値です。 手数料率は販売サービスごと・プランごとに違い、改定されることもあります。お使いのサービスの料金の案内を見て、自分の率に書き直してください。メモの列に「いつ確かめた率か」を書いておくと、改定に気づきやすくなります。

イベントの手売りは、現金なら手数料は 0 です。イベントでキャッシュレス決済を使う場合は、「イベント(キャッシュレス)」のように販売先を分けて、その決済サービスの率を書きます。

販売の記録を1行ずつ書く

売れたら、日付・販売先・作品名・数量・単価・受け取った送料・送料の実費を1行で書きます。

「受け取った送料」はお客さんから受け取った送料、「送料の実費」は自分が払った送料です。送料込みの価格で売っている場合は、受け取った送料を 0 にして、実費だけを書きます。

1行ごとの手数料を、販売先の表から引く

右側の列は式で出します。行2の式は次のとおりです(販売先の表は「設定」のシートの A5:B24 にあります)。

K2(売上):   =D2*E2+F2
L2(手数料): =IF(H2="",ROUND(K2*IFERROR(INDEX(設定!$B$5:$B$24,MATCH(B2,設定!$A$5:$A$24,0)),0),0),H2)
M2(原価):   =D2*IFERROR(INDEX(作品!$C$2:$C$201,MATCH(C2,作品!$A$2:$A$201,0)),0)
N2(利益):   =K2-L2-G2-M2
  • 売上は、数量 × 単価 に、受け取った送料を足したものです
  • 手数料は、H列の「手数料(実額)」が空なら式で出し、額が書いてあればその額を使います。式で出すときは、MATCH で販売先の表からその販売先の行を探し、INDEX で手数料率を取り出して、売上にかけます。ROUND(…,0) で1円未満を四捨五入しています。表に無い販売先は、IFERROR で率を 0 にしています(Excel 2021 以降や Microsoft 365 なら XLOOKUP(B2,設定!$A$5:$A$24,設定!$B$5:$B$24,0) でも同じことができます)
  • 原価は、数量 × 作品の表の「1点の原価」です
  • 利益は、売上 − 手数料 − 送料の実費 − 原価 です

この式では、手数料を「送料を含めた売上」にかけています。送料に手数料がかかるかどうかはサービスによって違うので、かからない場合は K2 の代わりに D2*E2 にかけます。また、式で出す手数料は概算です。正確な額は、各サービスの売上の明細で確かめてください。明細の額が分かったら、H列の「手数料(実額)」に書くと、式の値の代わりにその額を使います。送料に手数料がかかるかどうかで、送料込みの価格に切り替えるときの値段も変わります(送料と手数料の記事)。

販売先の名前は、販売の記録と販売先の表で1文字でも違うと見つからず、手数料が 0 になります。プルダウン(入力規則)で販売先の表から選ぶようにしておくと、打ちまちがいを防げます。

LibreOffice で、式の区切りが , ではなく ; の設定になっている場合は、, を ; に置き換えて入力します。

販売先ごとに SUMIFS で集計する

販売先別の表では、販売先の名前を条件にして、各列を SUMIFS で足します。行2の式は次のとおりです。

B2(記録の件数): =COUNTIFS(販売記録!$B:$B,$A2)
C2(販売数):     =SUMIFS(販売記録!$D:$D,販売記録!$B:$B,$A2)
D2(売上):       =SUMIFS(販売記録!$K:$K,販売記録!$B:$B,$A2)
E2(手数料):     =SUMIFS(販売記録!$L:$L,販売記録!$B:$B,$A2)
F2(利益):       =SUMIFS(販売記録!$N:$N,販売記録!$B:$B,$A2)
G2(利益率):     =IF(N(D2)=0,"",F2/D2)
H2(売上の割合): =IF(SUM(販売記録!$K:$K)=0,"",D2/SUM(販売記録!$K:$K))

例の数字では、次のようになりました。

販売先 売上 手数料 利益 利益率 売上の割合
minne 5,180円 549円 3,551円 68.6% 30.2%
Creema 3,230円 355円 2,345円 72.6% 18.8%
イベント 6,500円 0円 5,800円 89.2% 37.9%
自分のショップ 2,230円 125円 1,575円 70.6% 13.0%

4つの販売先の売上を足すと 17,140円 で、販売の記録の売上の合計と同じになります。合わないときは、販売先の名前が表と違う行があります。

利益率を比べるときの注意

この例では、イベントの利益率が 89.2% といちばん高く出ています。ただし、この表の利益には、出店料・交通費などのイベントの経費が入っていません。イベントの経費まで引いた利益は、ハンドメイドイベントの出店で、いくら残ったかを出す記事のように、イベントごとに出して比べてください。

同じように、minne の利益率が Creema より低いのは、手数料率の差だけが理由ではありません。この例の minne の行には、400円のしおりを送料120円で送った行があり、売上に占める送料の割合が高くなっています。受け取った送料と実費が同じなら、利益への影響は送料にかかる手数料の分だけですが、送料は売上に入るので、利益率は下がって見えます。率だけで「どの販売先が得か」を決めず、手数料・送料・原価のどれが効いているかを、行に戻って見ると判断しやすくなります。

手数料率が変わったとき

販売先の表の率を書き換えると、過去の行の手数料もすべて新しい率で計算し直されます。率が変わったときは、改定より前の行の「手数料(実額)」に額を書き込んでおくか、改定の日でファイルを分けると、過去の集計が変わりません(年ごとに分けているだけでは、年の途中の改定で同じ年の前の行も変わります)。

月ごとの集計のしかたは、BOOTH の売上を月別に集計する記事で説明しています(BOOTH の例ですが、同じ式で使えます)。

作った表を、そのまま使いたい方へ

この記事の画面は、販売記録・販売先別・月別の集計と、作品ごとの在庫までを1つにまとめたテンプレートで作りました。表を一から作る時間を省きたい方は、ハンドメイド売上・在庫管理シートもご覧ください。

確定申告について

この記事の表は、販売先ごとの売上を見比べるためのものです。売上や手数料を確定申告でどう扱うかは、国税庁のサイトの案内や、税務署・税理士に確認してください。
