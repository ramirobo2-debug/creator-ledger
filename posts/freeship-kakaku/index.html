送料無料にするなら、作品の価格をいくらにすれば同じ利益が残るかを出す

公開日: 2026-11-13

「送料無料のほうが買ってもらいやすいと聞くけれど、送料のぶん価格を上げるといくらになるの?」。いま「作品の価格+送料」で売っている作品を送料無料(送料込みの価格)に切り替えるときは、いまと同じ利益が残る下限の価格を先に出しておくと、値段を決めやすくなります。

ポイントは、送料だけでなく梱包資材と販売手数料も一緒に見ることです。いま送料に手数料がかかっていない販売先では、価格に送料を入れると、そのぶん手数料が増えます。

考え方: いまの利益をそのまま残せる価格を逆算する

  1. いまの利益 = いまの価格 + 受け取る送料 − 原価 − 手数料 − 払う送料 − 梱包資材
  2. 同じ利益になる下限の価格 =(いまの利益 + 原価 + 払う送料 + 梱包資材)÷(1 − 手数料の割合)
  3. 端数をそろえた価格 = 下限の価格を、10円・100円などの単位で切り上げた価格
  4. 送料込みにしたときの利益 = 送料込みの価格 − 原価 − 送料込みの価格 × 手数料の割合 − 払う送料 − 梱包資材

手数料は、送料にもかかる販売先なら「(いまの価格 + 受け取る送料)× 割合」、かからない販売先なら「いまの価格 × 割合」で出します(違いは送料と手数料の記事で比べています)。原価の出し方は原価の記事で説明しています。

表の作り方

「設定」のシートの B2 に販売手数料の割合、B3 に送料にも手数料がかかるか(かかる / かからない)、B4 に価格の端数をそろえる単位を入れます。「作品」のシートは1行1作品で、A 作品名・B いまの価格・C 受け取る送料・D 払う送料・E 梱包資材・F 原価・G 送料込みの価格(決めてあるとき)を入れます。

H2(いまの利益):        =B2+C2-F2-(B2+C2*IF(設定!$B$3="かからない",0,1))*設定!$B$2-D2-E2
I2(同じ利益になる下限): =ROUNDUP(ROUND((H2+F2+D2+E2)/(1-設定!$B$2),6),0)
J2(端数をそろえた価格): =ROUNDUP(ROUND(I2/設定!$B$4,6),0)*設定!$B$4
K2(使う送料込みの価格): =IF(ISNUMBER(G2),G2,J2)
L2(送料込みにしたときの利益): =K2-F2-K2*設定!$B$2-D2-E2
M2(差 送料込み − いま):  =L2-H2
N2(お客さまの支払いの差): =K2-(B2+C2)
  • I 列は、それより1円でも安いといまの利益を下回る境目なので、切り上げにしています。ROUND(…,6) は、割り算の小さな誤差で切り上げが1円ずれるのを防ぎます
  • G 列に価格を入れたときはそれを使い、空なら端数をそろえた価格を使います
  • 実際に使う表では、入力が足りない行や文字が入った行で #VALUE! が出ないよう、H 列を「入力がそろっているときだけ」計算し、I 列から先は H 列が数のときだけ計算する形にしています

例: 3つの作品を送料込みにする

手数料 10%(送料にもかかる)、端数は 100円単位でそろえるとします(数字は説明のための架空のものです)。

作品 いま(価格+送料) 下限 → そろえた価格 利益 いま → 送料込み 差
ピアス 1,200 + 180円 1,380 → 1,400円 652 → 670円 +18円
ネックレス 2,800 + 230円 3,030 →(2,980円を入れた) 1,517 → 1,472円 −45円
ヘアゴム 600 + 120円 720 → 800円 338 → 410円 +72円

ピアスは、いまお客さまが払っている 1,380円が、そのまま下限です。送料にも手数料がかかる販売先では、下限は「いまの価格 + 送料」と同じになります。100円単位にそろえて 1,400円にすると、お客さまの支払いは 20円増え、利益は 18円増えます。

ネックレスは「3,000円を切りたい」と 2,980円を入れた例です。下限の 3,030円より 50円安いので、利益は 45円減ります。2,980円にするか、3,100円にそろえるかは、この差を見て決めます。

数を見るときの注意

  • 払う送料は、送料込みにしても同じ配送方法で送る前提です。配送方法も変えるなら、いまの利益は今の送料のまま出しておき、下限は「(いまの利益 + 原価 + 変えたあとの送料 + 梱包資材)÷(1 − 手数料の割合)」で別に出します(この表は同じ送料の欄を前後で使うので、そのままでは比べられません)
  • 1回の注文で2個以上買われると、送料込みの価格では送料を作品の数だけ受け取る形になります。まとめ買いが多い作品は、利益の差が表より大きめに出ます
  • 送料込みにして売れる数が増えるかは、この表ではわかりません。切り替えたあとの販売数は、月別の売上の記事の形で前後を比べます
  • 送料と梱包資材を記録していない場合は、送料と梱包資材費の持ち出しの記事の形で、まず1回あたりの実際の額を出しておきます
  • 端数のそろえ方とお客さまの支払いの関係は、端数の記事で比べています

LibreOffice で式の区切りが ; の設定になっている場合は、, を ; に置き換えて入力します。

作った表を、そのまま使いたい方へ

この記事の表は、いまの「価格+送料」から送料込みの価格に切り替えるときの下限の価格、端数をそろえた価格、利益の差と判定まで出すテンプレートで作りました(入力の漏れや文字を赤で知らせる書式も入っています)。表を一から作る時間を省きたい方は、ハンドメイド 送料無料・送料込み価格の試算シートもご覧ください。
