入力のまちがいを色で知らせる|登録していない名前・空欄・重なりを条件付き書式で見つける

公開日: 2026-11-11

頒布記録や販売記録を SUMIFS で集計していると、「記録は書いたのに集計の数が合わない」ということが起きます。原因の多くは、作品名の後ろの空白、イベント名の打ちまちがい、部数の書き忘れのような小さな入力のまちがいです。式はエラーを出さずに 0 として数えるので、気づくのが遅れます。

この記事では、まちがえた行に色が付くように、条件付き書式を3つと、作品の表の重なりを見つけるルールを1つ足します。

まちがいがあると、集計はどうずれるか

この例の頒布記録には、まちがいが3つあります。

  • 3行目: 作品名が「新刊 」(後ろに空白)。作品の表に無い名前なので、使った単価が 0 になり、新刊の頒布数にも入りません
  • 4行目: 部数が空。売上が 0 のままです
  • 6行目: イベント名が「春イベンド」。作品の新刊には 5部が入りますが、イベントの表の「春イベント」の頒布部数は 0 のままです

作品の表の新刊は、本当は 28 + 3 + 5 = 36部のはずが 33部になります。どの式もエラーを出さないので、表を見ただけでは分かりません。

1. 作品の表に無い名前を赤にする

作品名の列(この例では B2:B201)を選んで、条件付き書式に「数式」のルールを足し、塗りつぶしを赤にします。

=AND($B2<>"",COUNTIF(作品!$A:$A,$B2)=0)
  • COUNTIF(作品!$A:$A,$B2) は、作品の表にその名前がいくつあるかを数えます。0 なら、表に無い名前です
  • $B2<>"" を付けて、まだ書いていない空の行には色を付けないようにします
  • 後ろの空白も別の文字として扱われるので、「新刊 」の行が赤くなります

イベント名の列(A2:A201)にも、同じ形のルールを足します。

=AND($A2<>"",COUNTIF(イベント!$A:$A,$A2)=0)

2. 書き忘れた空欄を赤にする

部数の列(C2:C201)には、「作品名は書いたのに部数が空」の行だけ色を付けます。

=AND($B2<>"",$C2="")

部数だけを見て「空なら赤」にすると、まだ使っていない下の行まで全部赤くなります。同じ行のほかの列(ここでは作品名)が埋まっているかどうかを条件に入れるのがポイントです。

3. 作品の表の重なりを赤にする

作品の表に同じ名前が2回あると、SUMIFS はどちらの行にも同じ数を返すので、頒布数も在庫も二重に見えます。作品名の列(作品シートの A2:A201)に、次のルールを足します。

=AND($A2<>"",COUNTIF($A$2:$A$201,$A2)>1)

範囲は $A$2:$A$201 と行まで固定し、数える名前は $A2 と列だけ固定します。こうすると、どの行も「表全体の中で、自分と同じ名前がいくつあるか」を数えます。

まちがいの数を1つのセルで出す

色は、表を上から見ていかないと気づきません。表の上やまとめのシートに、まちがいの数を出しておくと、0 かどうかだけを見れば済みます。

=SUMPRODUCT((B2:B201<>"")*(COUNTIF(作品!A:A,B2:B201)=0))

この例では 1(3行目の「新刊 」)です。COUNTIF の2つ目の引数に範囲を渡すと、1行ずつ数えた結果がまとめて返り、SUMPRODUCT がそれを足します。

色を付ける前に、まちがいを減らす

  • プルダウンで選ばせる: このテンプレートでは、頒布記録のイベント名・作品名を、入力規則のプルダウンで選ぶようにしてあります。それでも、ほかの表からの貼り付けや、規則を付ける前の行では、まちがいが入ります。条件付き書式は、その取りこぼしを見つけるためのものです
  • 空白を消す: 名前の後ろの空白は、TRIM で消せます(作品名から価格を引く式で空白が原因のときの直し方は、価格を引く式の記事で説明しています)
  • 色の重なり: 在庫の数に色を付けるルール(在庫が少なくなったら色で知らせる記事)と同じ範囲に重ねるときは、まちがいの赤を優先する順に並べます

ソフトごとの違い

  • Excel: 「ホーム」→「条件付き書式」→「新しいルール」→「数式を使用して、書式設定するセルを決定」。Excel 2010 以降なら、ほかのシート(作品!$A:$A)をそのまま書けます
  • LibreOffice: 「書式」→「条件」→「条件」で、条件を「数式が」にします。式の区切りが ; の設定のときは、, を ; に置き換えます
  • Google スプレッドシート: 「表示形式」→「条件付き書式」→「カスタム数式」。条件付き書式の式からほかのシートを見るときは、INDIRECT("作品!A:A") の形で書きます

作った表を、そのまま使いたい方へ

この記事の頒布記録は、作品・イベント・頒布記録・まとめを1つにまとめたテンプレートで作りました(この記事の赤のルールは、記事で足したものです)。イベント名・作品名をプルダウンで選べるようにしてあり、頒布数・在庫・収支が式で出ます。表を一から作る時間を省きたい方は、同人イベント頒布管理シートもご覧ください。
